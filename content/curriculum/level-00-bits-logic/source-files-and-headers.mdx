So far every program in this course has been one file. Real programs are hundreds or thousands of files. C has a simple, old-fashioned way to let them use each other's functions: header files and a step called the <b>preprocessor</b>.

By the end you'll be able to tell a declaration from a definition, say exactly what #include does, and see the text the compiler really receives.

## Declaring versus defining

A <b>definition</b> is the thing itself. This is a definition of a function: it has a body, and the compiler turns that body into instructions.

```c
int square(int x) {
    return x * x;
}
```

A <b>declaration</b> only tells the compiler that a name exists and what type it has. It's a promise: "somewhere, there is a function called square that takes an int and returns an int."

```c
int square(int x);
```

The compiler needs the promise before it can compile a call. When it reaches `square(i)` in another file, it doesn't need the body; it only needs to know which arguments to pass and what comes back. Finding the actual body is someone else's job, later.

<KeyIdea>A declaration says a name exists and gives its type. A definition is the thing itself. Declare as often as you need; define exactly once.</KeyIdea>

## Header files hold the promises

To use `square` from several files, you'd have to type its declaration into each one. Instead, C programs put shared declarations in a <b>header file</b>, ending in `.h`, and each file that needs them includes it. Here is a small program in three files:

```c
/* square.h: a declaration only. */
int square(int x);
```

```c
/* square.c */
#include "square.h"

int square(int x) {
    return x * x;
}
```

```c
/* main.c */
#include <stdio.h>
#include "square.h"

int count = 3;
int results[3];
const char greeting[] = "squares:";

int main(void) {
    printf("%s\n", greeting);
    for (int i = 1; i <= count; i++) {
        results[i - 1] = square(i);
        printf("%d\n", results[i - 1]);
    }
    return 0;
}
```

`square.c` defines `square`. `main.c` only declares it (through the header) and calls it. `stdio.h` is the standard library's header: it declares `printf`. Angle brackets mean "look in the system's folders"; quotes mean "look next to this file first".

## #include is copy and paste

Lines starting with `#` are not C. They're instructions to the preprocessor, which runs before the compiler and works only on text. `#include "square.h"` means: replace this line with the whole text of square.h.

That's all. The preprocessor doesn't understand C; it pastes. `#define LIMIT 3` is the same idea: from then on, every `LIMIT` in the text is replaced by `3` before the compiler sees it.

<KeyIdea>The preprocessor edits text before compiling: #include pastes a file in, #define replaces a word. The compiler never sees the # lines.</KeyIdea>

## Seeing what the compiler sees

`gcc -E` runs only the preprocessor and prints the result. Here is the end of `gcc -E main.c`, run with gcc 15.2 on x86-64 Linux:

```
...
# 2 "main.c" 2
# 1 "square.h" 1


# 2 "square.h"
int square(int x);
# 3 "main.c" 2

int count = 3;
int results[3];
const char greeting[] = "squares:";

int main(void) {
    printf("%s\n", greeting);
...
```

Three things to notice:

- The text of square.h is now inside main.c, with its comment removed. The lines starting with `# 2 "square.h"` are markers telling the compiler which file each line came from, so its error messages can name the right file.
- Above this, the preprocessor pasted in all of stdio.h. The 15-line main.c became 856 lines. Somewhere in them is the declaration of printf: `extern int printf (const char *__restrict __format, ...);`.
- Your own lines arrive unchanged.

The exact output differs between compilers and systems (another C library has a different stdio.h), but the idea is the same everywhere.

<details>
<summary>Check your answer: what would happen if main.c didn't include square.h?</summary>

The compiler reaches `square(i)` with no declaration. gcc 15 stops with an error:

```
noinc.c: In function ‘main’:
noinc.c:10:26: error: implicit declaration of function ‘square’ [-Wimplicit-function-declaration]
```

It can't check the call against a promise it never saw. The fix is the header: one shared promise, pasted into every file that needs it.
