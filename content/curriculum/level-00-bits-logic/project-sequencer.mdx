This is an optional extra. It puts a state machine and memory together: the state machine says what to do on each step, and you carry it out on the memory board.

## Part 1: Three steps, then repeat

Build a sequencer with a 2-bit state, S1 and S0. While GO is 1, it should step 00, 01, 10 and then back to 00. Three wires should say which step it's on: READ is 1 in step 00, ADD in step 01, WRITE in step 10.

<ClockLab caption='A three-step sequencer' inputsJson='["GO"]' registersJson='["S1","S0"]' outputsJson='["READ","ADD","WRITE"]' startJson='["S0 := NOT S0","S1 := S1","READ = 1","ADD = 0","WRITE = 0"]' targetJson='["S0 := GO AND NOT S1 AND NOT S0","S1 := GO AND S0","READ = NOT S1 AND NOT S0","ADD = S0","WRITE = S1"]' ticksJson='[{"GO":1},{"GO":1},{"GO":1},{"GO":1},{"GO":1},{"GO":1}]' />

Each row of the timeline shows the state after that tick, and the three wires for that state.

<details>
<summary>Check your answer</summary>

- `S0 := GO AND NOT S1 AND NOT S0`: go to 01 only from 00.
- `S1 := GO AND S0`: go to 10 only from 01.
- From 10, both lines give 0, so it returns to 00.
- `READ = NOT S1 AND NOT S0`, `ADD = S0`, `WRITE = S1`.

The state runs 01, 10, 00, 01, 10, 00 after each tick, and in each step exactly one of READ, ADD and WRITE is 1.

</details>

## Part 2: Do what it says

Box 5 holds 20. Follow your sequencer's steps on the memory board to add 1 to it: in the READ step, read box 5; in the ADD step, add 1 in your head (you're the ALU); in the WRITE step, write the result back. The goal is box 5 holding 21.

<MemoryBoard caption='Read, add, write' sizeJson='16' startJson='{"5":20}' goalJson='{"5":21}' />

<details>
<summary>Check your answer</summary>

READ: address 5, write enable off, data out shows 20. ADD: 20 + 1 = 21. WRITE: address 5, data in 21, write enable on, Tick. One trip round the sequencer is one read-modify-write.

Now picture the sequencer's wires connected instead of you following them: READ turning on memory's output, ADD turning on the ALU, WRITE turning on write enable. That is a control unit, and it's what you'll build next, in Build a CPU.

</details>

## Done when

The sequencer is solved, the board says "Done", and you can say what a control unit does in one sentence.
