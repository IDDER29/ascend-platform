A computer is often called a machine that follows instructions. That is true, but it hides how literal the following is. A person can fill gaps, guess what you meant, or skip a step that looks silly. A machine does exactly what each step says, in order, and nothing else.

By the end you'll be able to say what an algorithm is, what an instruction is, and follow a short algorithm by hand the way a machine would.

## A recipe a machine could follow

A recipe is a list of steps, but most recipes lean on the cook's judgement: "season to taste", "bake until golden". A machine has no taste and no idea what golden looks like. For a machine, every step has to be something it can check or do exactly.

## What makes an algorithm

An <b>algorithm</b> is a procedure with three properties:

- <b>Exact steps</b>: each step can only be carried out one way.
- <b>A definite order</b>: it is always clear which step comes next.
- <b>An end</b>: it finishes, with an answer.

Here is an algorithm for finding the largest number in a list:

1. Hold the first number.
2. Look at the next number. If it is bigger than the one you hold, hold it instead.
3. If there are numbers left, go back to step 2.
4. The number you hold is the answer.

<KeyIdea>An algorithm is exact, ordered and finishes. If a step needs judgement, it isn't ready for a machine.</KeyIdea>

## Instructions: steps a machine recognises

An algorithm says what to do. A machine can only do the things it was built to do. Each of those built-in actions is an <b>instruction</b>: "add these two numbers", "copy this value", "if this is zero, go to that step".

To run an algorithm, it has to be written as a sequence of the machine's own instructions. "Hold it if it is bigger" might become three instructions: compare, check the result, copy. Each one is simple; the algorithm comes from their order.

Instructions are stored the same way as everything else: as bit patterns, read with a code the machine was built to understand. Later in this path you'll meet exactly such a code for a tiny CPU.

## From steps to a running machine

So there are two layers. The algorithm is the idea: find the largest number. The instructions are the machine's way of carrying it out, one small step at a time. The same algorithm can be written for very different machines, each with its own set of instructions.

<KeyIdea>An algorithm is the plan. Instructions are the machine's own steps for carrying it out.</KeyIdea>
