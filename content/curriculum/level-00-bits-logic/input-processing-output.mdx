The last lesson said every computer takes in information, works on it, remembers and follows instructions. Inside a real machine, different parts do those jobs. In this lesson you'll follow one everyday task through all of them.

By the end you'll be able to name the main parts of a computer by what they do, and explain why a computer has two kinds of memory.

## The parts, by their jobs

<TruthTable caption='The main parts of a computer' rowsJson='[["job", "part", "examples"], ["input", "input devices", "keyboard, camera, microphone, touch screen"], ["processing", "the CPU (central processing unit)", "the chip that follows the program"], ["memory", "RAM (main memory)", "holds what the CPU is working on right now"], ["storage", "a drive (SSD or hard disk)", "keeps files and programs with the power off"], ["output", "output devices", "screen, speaker, printer"]]' />

Devices that sit around the CPU and memory, such as keyboards, screens and drives, are called <b>peripherals</b>. The <b>CPU</b> is the part that follows the program's instructions one by one. Everything else feeds it information or takes information away.

## One photo, from start to finish

Take a photo on a phone and every part gets a turn:

1. <b>Input</b>: the camera turns light into numbers.
2. <b>Memory</b>: those numbers are put in RAM, where the CPU can reach them quickly.
3. <b>Processing</b>: the CPU follows the camera app's instructions to brighten the image and shrink it into a file.
4. <b>Storage</b>: the file is written to the phone's storage, so it is still there tomorrow.
5. <b>Output</b>: the screen shows you the photo.

The order isn't always the same. Opening an old photo starts with storage (the file is copied into memory), then processing, then output.

<KeyIdea>Input brings information in, the CPU works on it in memory, storage keeps it, and output sends it back out.</KeyIdea>

## Memory and storage are different

People often say "memory" for both, but a computer has two very different kinds.

- <b>Memory</b> (RAM) is where the CPU does its work. It is fast, but it is <b>volatile</b>: it forgets everything when the power goes off.
- <b>Storage</b> (an SSD or hard disk) keeps data with the power off. It is much slower, but it holds far more for the same price.

That is why a program you open is first copied from storage into memory, and why work you haven't saved can vanish in a power cut: it was only in memory.

<KeyIdea>Memory is fast and forgets; storage is slow and keeps. A running program lives in memory, a saved file lives in storage.</KeyIdea>

Later in Foundations you'll build memory from circuits and see exactly why it forgets. For now, the map is enough: five jobs, each done by its own part.
