An <b>assembler</b> is the program that turns assembly into bytes. It reads the whole program twice. The first reading, <b>pass one</b>, writes nothing. It only works out where every instruction will go and what every label means.

By the end you'll be able to do pass one by hand, and explain why the second pass is needed.

## The location counter

Pass one keeps a single number, the <b>location counter</b>: the address the next instruction will get. It starts at 0x00. For each line:

- if the line has an instruction, that instruction gets the counter's value as its address, and the counter goes up by 2;
- if the line defines a label, the label gets the counter's value (the address of the next instruction).

Every tiny CPU instruction is exactly two bytes, so the counter always moves in steps of 2.

## Labels take no space

A comment, a blank line or a line holding only a label isn't an instruction, so it adds nothing to the counter. In this program the line `loop:` stands alone; it names the address of the ADD below it:

At the end, the <b>label table</b> holds one entry: loop = 0x04. The program shows 15.

<KeyIdea>Pass one counts. Each instruction moves the counter on by 2; a label just writes down where the counter is.</KeyIdea>

## Why two passes

A label can be used before it's defined. In this program, JZ done comes two lines before `done:`. Do pass one for it:

<AssemblerLab caption='Pass one with a forward jump' programJson='["LDI R0, 3", "loop: OUT R0", "DEC R0", "JZ done", "JMP loop", "done: HALT"]' passJson='1' />

<details>
<summary>Check your answer</summary>

The addresses are 0x00, 0x02, 0x04, 0x06, 0x08 and 0x0A, so loop = 0x02 and done = 0x0A.

When the assembler first reaches JZ done, at 0x06, it hasn't seen `done:` yet: it only learns that done is 0x0A at the last line. That's why it can't write JZ done's bytes on the way down. After pass one, the label table is complete, and pass two can write every instruction, forward jumps included.

</details>

<KeyIdea>Pass one finds every name; pass two uses them. Two passes are what let a jump point forward.</KeyIdea>
